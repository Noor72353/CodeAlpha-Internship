# CodeAlpha AI Internship Projects

This repository contains the projects I developed during my **Artificial Intelligence Internship at CodeAlpha (November 2026)**. It brings together four practical projects covering computer vision, natural language processing, language translation, and deep learning-based music generation.

## Projects

### 1. Object Detection and Tracking
A computer vision project that detects and tracks objects in video streams using YOLO11n and ByteTrack.

**Technologies:** Python, OpenCV, Ultralytics YOLO11n, ByteTrack, NumPy.

[View Project](./Object-Detection-and-Tracking/)

### 2. FAQ Chatbot
An NLP-based chatbot that responds to frequently asked questions using TF-IDF vectorization and cosine similarity.

**Technologies:** Python, NLP, scikit-learn, TF-IDF, Cosine Similarity, Streamlit.

[View Project](./FAQ-Chatbot/)

### 3. Language Translation Tool
A simple language translation application that provides translations through the MyMemory Translation API.

**Technologies:** Python, Streamlit, Requests, MyMemory Translation API.

[View Project](./Language-Translation-Tool/)

### 4. Music Generation
A deep learning-based project exploring automated music generation using neural networks.

**Technologies:** Python, TensorFlow, Keras, NumPy, music21.

[View Project](./Music-Generation/)

## Technologies and Skills

- **Programming:** Python
- **Computer Vision:** OpenCV, YOLO11n, ByteTrack
- **Machine Learning and Deep Learning:** TensorFlow, Keras, scikit-learn
- **Natural Language Processing:** TF-IDF, Cosine Similarity
